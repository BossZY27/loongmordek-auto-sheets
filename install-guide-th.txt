คู่มือติดตั้ง Loongmordek Auto Sheets
====================================

ระบบนี้รับข้อความคอนเทนต์จาก AI หนึ่งชุด แล้วแยกเป็นข้อมูลสำหรับ Facebook,
Instagram, TikTok และ YouTube Shorts ใน Google Sheets เพื่อให้ตรวจทานก่อนส่งต่อ
ให้ระบบโพสต์ภายนอก

ข้อควรทราบก่อนเริ่ม
-------------------

1. ใช้บัญชี Google ที่เป็นเจ้าของหรือได้รับสิทธิ์แก้ไขชีต
2. เลือกใช้ Code.gs หรือ Code_due_queue.gs เพียงไฟล์เดียว
3. Code.gs สร้าง 4 แถวในชีต Loongmordek Content ทันทีด้วยสถานะ รอตรวจ
4. Code_due_queue.gs ใช้คิวตามเวลาและเขียนไปที่ชีต ชีต1
5. ตรวจว่าไม่มีข้อมูลลูกค้าหรือ Spreadsheet ID จริงอยู่ในไฟล์ที่จะเผยแพร่

ขั้นตอนที่ 1: เตรียม Google Sheet
---------------------------------

เปิด Google Sheet ที่ต้องการใช้ แล้วคัดลอก Spreadsheet ID จาก URL

ตัวอย่าง URL:
https://docs.google.com/spreadsheets/d/SPREADSHEET_ID/edit

ข้อความระหว่าง /d/ และ /edit คือ Spreadsheet ID

สร้างหรือตรวจชื่อชีต output ให้ตรงกับไฟล์ที่เลือก:

- Code.gs: Loongmordek Content
- Code_due_queue.gs: ชีต1

ขั้นตอนที่ 2: ตั้งค่าและวางโค้ด
--------------------------------

1. เปิด Extensions > Apps Script
2. เปิด source file ที่เลือกจาก repository
3. แทนค่า PASTE_SPREADSHEET_ID_HERE ด้วย Spreadsheet ID ของชีตนี้
4. คัดลอก source file ที่ตั้งค่าแล้วไปวางใน Code.gs ของ Apps Script
5. กด Save

อย่านำ Code.gs และ Code_due_queue.gs มารวมกัน เพราะมีชื่อ constant และ function ซ้ำกัน

ขั้นตอนที่ 3: สร้างแท็บ AI Input
---------------------------------

1. เลือกฟังก์ชัน setupAiInputSheet
2. กด Run
3. ตรวจชื่อโปรเจกต์ บัญชี และรายการสิทธิ์ที่ Google แสดง
4. อนุญาตเฉพาะเมื่อเป็น project ที่สร้าง/ตรวจสอบเองและสิทธิ์สอดคล้องกับงาน

หลังทำงานสำเร็จจะมีแท็บ AI Input พร้อมหัวคอลัมน์ที่ระบบต้องใช้

ขั้นตอนที่ 4: ติดตั้ง Trigger
----------------------------

1. เลือกฟังก์ชัน installAutoSheetsTrigger
2. กด Run
3. เปิดหน้า Triggers ใน Apps Script เพื่อตรวจว่ามี processAiInputRows ทุก 5 นาที

ฟังก์ชันติดตั้งจะลบ trigger เดิมของ processAiInputRows ก่อนสร้างใหม่ เพื่อหลีกเลี่ยง
การประมวลผลซ้ำจาก trigger หลายตัว

วิธีใช้งาน
----------

เพิ่มแถวในแท็บ AI Input โดยกรอก:

- Status: รอแปลง
- AI Raw Content: ข้อความตามรูปแบบใน sample-ai-content.txt หรือ
  sample-ai-content-simplified.txt
- File ID: File ID จาก Google Drive ไม่ใช่ URL ทั้งเส้น
- Video Name: ชื่อคลิปที่ใช้ระบุงาน
- Start Time: วัน/เดือน/ปี/ ชั่วโมง:นาที เช่น 15/07/2026/ 10:00
- Interval Minutes: ระยะห่างของแต่ละแพลตฟอร์ม เช่น 5

ตัวอย่างสังเคราะห์
------------------

Start Time: 15/07/2026/ 10:00
Interval Minutes: 5

เวลาที่เตรียมได้:

- Facebook: 15/07/2026 10:00
- Instagram: 15/07/2026 10:05
- TikTok: 15/07/2026 10:10
- YouTube Shorts: 15/07/2026 10:15

ตัวอย่างนี้ใช้เพื่ออธิบายการคำนวณเท่านั้น ไม่ใช่ผลจาก production

ขั้นตอนตรวจทาน
--------------

1. ตรวจ Caption, Hashtag, File ID, Video Name และเวลา
2. ตรวจว่าไม่มีข้อมูลส่วนบุคคลหรือข้อความที่ไม่ควรเผยแพร่
3. เปลี่ยนสถานะเป็น รอคิว เฉพาะรายการที่อนุมัติแล้ว
4. ทดสอบระบบโพสต์ปลายทางด้วยบัญชี sandbox/test ก่อนใช้บัญชีจริง

การทดสอบ Parser โดยไม่เชื่อม Google
------------------------------------

เปิด PowerShell ในโฟลเดอร์ repository แล้วรัน:

node test-parser.js sample-ai-content.txt
node test-parser.js sample-ai-content-simplified.txt

การทดสอบนี้ตรวจเฉพาะ parser ไม่ได้ทดสอบ Apps Script trigger, Google Sheets
หรือระบบโพสต์ภายนอก

การแก้ปัญหา
------------

- ไม่พบชีต: ตรวจ OUTPUT_SHEET_NAME และชื่อแท็บจริง
- ข้อมูลไม่ถูกแยก: เทียบหัวข้อใน AI Raw Content กับไฟล์ตัวอย่าง
- วันเวลาไม่ถูกต้อง: ใช้รูปแบบ วัน/เดือน/ปี/ ชั่วโมง:นาที
- ไม่มีการประมวลผล: ตรวจ Status, Trigger และ Execution log ใน Apps Script
- พบ error: อ่าน Output Status และ Error Message ใน AI Input โดยไม่ส่งข้อมูลจริง
  หรือ credential ผ่านช่องทางสาธารณะ
